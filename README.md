Day 26: Data Privacy Basics

Project Overview

This project focuses on identifying sensitive information, classifying data, and recommending basic data protection measures as part of my cybersecurity internship at VEDA TECHNOLOGY.

Objective

To understand data classification and data protection principles and learn how to protect customer information.

Tools Used

- Google Sheets
- GitHub
- CSV files

Data Classification

Data is classified into four categories:

1. Public: Information intended for public access.
2. Internal: Information intended for authorized organizational use.
3. Confidential: Information that requires restricted access.
4. Sensitive: Information requiring strong protection, such as passwords and financial credentials.

Security Measures

- Apply least-privilege access control.
- Encrypt sensitive data.
- Use strong passwords and multi-factor authentication.
- Collect only necessary information.
- Mask or anonymize personal information where appropriate.
- Review access permissions regularly.

Deliverables

- Data classification table
- Sample synthetic customer dataset
- Privacy protection recommendations

Key Learnings

I learned how to categorize information based on confidentiality and risk, identify potential privacy threats, and recommend appropriate security controls.

Disclaimer

All customer records used in this project are fictional and created for educational purposes.

Conclusion

Data classification and privacy protection are essential components of cybersecurity. Appropriate controls help reduce unauthorized access, data exposure, and privacy risks.
